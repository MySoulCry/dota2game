## Шаг 1. Создать репозиторий и залить сайт

### Вариант А — сделать руками (5 минут)

1. github.com → **New repository**.
2. Имя: `dota2game`. Видимость: **Public** (Pages на бесплатном аккаунте работают только в публичных репозиториях). → **Create**.
3. В репозитории: **Add file → Upload files**, перетащить **всё содержимое папки проекта**: `index.html`, `styles.css`, `privacy.html`, `ads.txt`, `CNAME`, `.nojekyll`, папку `js`.
4. Если `.nojekyll` не загрузился (браузер иногда пропускает файлы, начинающиеся с точки): **Add file → Create new file**, имя `.nojekyll`, содержимое пустое → Commit.
5. **Commit changes**.

### Вариант Б — я сделаю сам

Напиши в чат «создавай» — я создам репозиторий `MySoulCry/dota2game`, подключу его и залью все файлы. Дальше останется включить Pages по шагу 2.

## Шаг 2. Включить GitHub Pages

1. Репозиторий → **Settings → Pages**.
2. **Source: Deploy from a branch** → Branch: `main`, folder: `/ (root)` → **Save**.
3. В поле **Custom domain** должен подставиться `dota2game.site` (он берётся из файла `CNAME`). Если пусто — впиши вручную и нажми **Save**.

> Пока DNS не настроен, адрес `https://mysoulcry.github.io/dota2game/` будет перенаправлять на `dota2game.site` и выглядеть «неоткрывающимся». Это нормально и пройдёт после шага 3.

---

## Шаг 3. DNS в личном кабинете reg.ru

1. Войди на reg.ru → **Мои домены** → `dota2game.site` → **Управление зоной** (иногда называется «DNS-серверы и зона»).
2. Проверь **NS-серверы**: должны быть `ns1.reg.ru` и `ns2.reg.ru`. Если там что-то другое — DNS редактируется не здесь, напиши мне, разберёмся.
3. Если включён сервис **«Парковка»** — отключи его: он добавляет свою A-запись и мешает GitHub.
4. Удали лишние A-записи, которые reg.ru поставил по умолчанию (обычно A на парковочный IP).
5. Добавь записи:

**A (четыре штуки, имя `@`):**

```
@    A    185.199.108.153
@    A    185.199.109.153
@    A    185.199.110.153
@    A    185.199.111.153
```

**AAAA (четыре штуки, имя `@`):**

```
@    AAAA    2606:50c0:8000::153
@    AAAA    2606:50c0:8001::153
@    AAAA    2606:50c0:8002::153
@    AAAA    2606:50c0:8003::153
```

**CNAME (для www):**

```
www    CNAME    mysoulcry.github.io.
```

TTL — `3600` (или «по умолчанию»). Сохранить.

6. Подожди 10–60 минут. Проверка: https://dnschecker.org → `dota2game.site` → должны быть все четыре IP GitHub.

## Шаг 4. HTTPS и проверка

1. Вернись в **Settings → Pages**. Когда GitHub выпустит сертификат (до 24 часов), появится галочка **Enforce HTTPS** — включи её.
2. Проверь по списку:
   - [ ] `https://dota2game.site` открывается без предупреждений браузера;
   - [ ] запускается раунд, матчи подгружаются;
   - [ ] `https://dota2game.site/privacy.html` открывается;
   - [ ] в `privacy.html` вместо «укажи здесь свой e-mail» стоит рабочий адрес;
   - [ ] в онлайне создаётся комната.

## Шаг 5. Яндекс Реклама (РСЯ)

1. **Кабинет:** yandex.ru/ads → стать площадкой, добавить сайт `dota2game.site`.
2. **Подтверждение владения:** в кабинете будет кнопка «Проверить права на сайт» — она даст `<meta name="yandex-verification" content="...">`. Пришли мне значение, я вставлю его в `index.html` (там уже оставлено закомментированное место) и запушу. Либо сделай сам: раскомментируй строку.
3. **Договор:** самозанятый / ИП / ООО. Без него деньги начисляются, но не выплачиваются.
4. **Модерация площадки:** 1–5 рабочих дней.
5. **Блоки:** создай два адаптивных баннера. Получишь id вида `R-A-1234567-1`. Пришли их мне — впишу в настройки и проверю, что баннеры отрисовались.

## Шаг 6. Пока реклама не идёт

- **Донат:** Boosty или DonationAlerts → ссылка в настройки, кнопки «Поддержать» уже на сайте.
- **Партнёрка / Telegram-канал** рядом с игрой.
- Прямой баннер у знакомого магазина или сообщества.

Не кликай по своей рекламе и не проси об этом других.
