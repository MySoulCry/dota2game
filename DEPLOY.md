# Пошагово: публикация `dota2game.site`

Текущий статус:

- ✅ домен `dota2game.site` куплен (reg.ru)
- ✅ домен прописан в проекте: `CNAME`, `canonical`, `og:url`
- ✅ репозиторий создан и залит: https://github.com/MySoulCry/dota2game
- ⬜ DNS не настроен
- ⬜ Pages не включён
- ⬜ реклама (РСЯ) не подключена

**Порядок важен:** сначала DNS, потом включение Pages. Иначе адрес `mysoulcry.github.io/dota2game/` будет перенаправлять на ещё не работающий домен и сайт будет казаться сломанным.

GitHub-аккаунт: **MySoulCry**.

## Шаг 1. Репозиторий

Готово: https://github.com/MySoulCry/dota2game (public, ветка `main`, все файлы на месте, `CNAME` с доменом внутри).

## Шаг 2. DNS в личном кабинете reg.ru — делаем сейчас

NS-серверы уже правильные (`ns1.reg.ru`, `ns2.reg.ru`) — значит записи редактируются здесь же, в «Ресурсные записи».

Сейчас в зоне стоят две записи парковки Рег.ру — их надо **удалить**, иначе домен будет иногда открывать заглушку вместо игры:

```
A   @     95.163.244.138   ← удалить
A   www   95.163.244.138   ← удалить
```

Порядок действий:

**Что писать в поле «Имя» / «Subdomain»** (главная путаница в этой панели):

- для записей **на сам домен** (A и AAAA) — оставь поле **пустым**; если пустое не принимает — впиши `@`;
- для `www` — впиши `www`;
- полный адрес (`dota2game.site`) в это поле писать **не надо**: панель сама допишет `.dota2game.site`, и получится `dota2game.site.dota2game.site`.

1. Удали **обе** A-записи (`@` и `www`) — по кнопке удаления рядом с записью.
2. **Добавить запись** → тип `A` → имя `@` → значение `185.199.108.153` → TTL `3600` → Сохранить.
3. Так же добавь ещё три A на `@`:
   - `185.199.109.153`
   - `185.199.110.153`
   - `185.199.111.153`
4. **Добавить запись** → тип `AAAA` → имя `@` → четыре значения:
   - `2606:50c0:8000::153`
   - `2606:50c0:8001::153`
   - `2606:50c0:8002::153`
   - `2606:50c0:8003::153`
5. **Добавить запись** → тип `CNAME` → имя `www` → значение `mysoulcry.github.io.` (точка на конце — можно и без, Рег.ру допишет) → TTL `3600`.

Важно: `www` должен быть именно CNAME. CNAME нельзя ставить рядом с A-записью на том же имени, поэтому старую `A www` удаляем первой.

Итог в панели: 4 A на `@`, 4 AAAA на `@`, 1 CNAME на `www`. Никаких записей на `95.163.244.138` остаться не должно.

**Что сейчас с доменом:** публичный DNS отвечает `NXDOMAIN` — домен ещё не виден в реестре зоны `.site`. Это нормально в первые часы после покупки: регистратор передаёт домен в реестр, и только после этого записи из панели начинают работать. Если через сутки всё так же — проверь в кабинете Рег.ру, что домен в статусе «Активен» и оплачен.

Проверка через 10–60 минут после делегирования: https://dnschecker.org → `dota2game.site` → должны быть все четыре IP GitHub.

## Шаг 3. Включить GitHub Pages (после того как DNS применился)

1. https://github.com/MySoulCry/dota2game → **Settings → Pages**.
2. **Source: Deploy from a branch** → Branch: `main`, folder: `/ (root)` → **Save**.
3. Поле **Custom domain** должно само заполниться `dota2game.site` из файла `CNAME`. Если пусто — впиши вручную и нажми **Save**.
4. Через минуту-две сайт откроется на `https://dota2game.site`.

## Шаг 4. HTTPS и проверка

1. Вернись в **Settings → Pages**. Когда GitHub выпустит сертификат (до 24 часов), появится галочка **Enforce HTTPS** — включи её.
2. Проверь по списку:
   - [ ] `https://dota2game.site` открывается без предупреждений браузера;
   - [ ] запускается раунд, матчи подгружаются;
   - [ ] `https://dota2game.site/privacy.html` открывается;
   - [ ] в `privacy.html` вместо «укажи здесь свой e-mail» стоит рабочий адрес;
   - [ ] в онлайне создаётся комната.

## Шаг 5. Яндекс Реклама (РСЯ)

1. **Кабинет:** yandex.ru/ads → стать площадкой, добавить сайт `dota2game.site`.
2. **Подтверждение владения:** в кабинете будет кнопка «Проверить права на сайт» — она даст `<meta name="yandex-verification" content="...">`. Пришли мне значение, я вставлю его в `index.html` (там уже оставлено закомментированное место) и запушу. Либо сделай сам: раскомментируй строку.
3. **Договор:** самозанятый / ИП / ООО. Без него деньги начисляются, но не выплачиваются.
4. **Модерация площадки:** 1–5 рабочих дней.
5. **Блоки:** создай два адаптивных баннера. Получишь id вида `R-A-1234567-1`. Пришли их мне — впишу в настройки и проверю, что баннеры отрисовались.
