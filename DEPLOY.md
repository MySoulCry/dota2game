## Шаг 2. DNS в личном кабинете reg.ru — делаем сейчас

NS-серверы уже правильные (`ns1.reg.ru`, `ns2.reg.ru`) — значит записи редактируются здесь же, в «Ресурсные записи».

Сейчас в зоне стоят две записи парковки Рег.ру — их надо **удалить**, иначе домен будет иногда открывать заглушку вместо игры:

```
A   @     95.163.244.138   ← удалить
A   www   95.163.244.138   ← удалить
```

Порядок действий:

**Что писать в поле «Имя» / «Subdomain»** (главная путаница в этой панели):

- для записей **на сам домен** (A и AAAA) — оставь поле **пустым**; если пустое не принимает — впиши `@`;
- для `www` — впиши `www`;
- полный адрес (`dota2game.site`) в это поле писать **не надо**: панель сама допишет `.dota2game.site`, и получится `dota2game.site.dota2game.site`.

1. Удали **обе** A-записи (`@` и `www`) — по кнопке удаления рядом с записью.
2. **Добавить запись** → тип `A` → имя `@` → значение `185.199.108.153` → TTL `3600` → Сохранить.
3. Так же добавь ещё три A на `@`:
   - `185.199.109.153`
   - `185.199.110.153`
   - `185.199.111.153`
4. **Добавить запись** → тип `AAAA` → имя `@` → четыре значения:
   - `2606:50c0:8000::153`
   - `2606:50c0:8001::153`
   - `2606:50c0:8002::153`
   - `2606:50c0:8003::153`
5. **Добавить запись** → тип `CNAME` → имя `www` → значение `mysoulcry.github.io.` (точка на конце — можно и без, Рег.ру допишет) → TTL `3600`.

Важно: `www` должен быть именно CNAME. CNAME нельзя ставить рядом с A-записью на том же имени, поэтому старую `A www` удаляем первой.

Итог в панели: 4 A на `@`, 4 AAAA на `@`, 1 CNAME на `www`. Никаких записей на `95.163.244.138` остаться не должно.

**Что сейчас с доменом:** публичный DNS отвечает `NXDOMAIN` — домен ещё не виден в реестре зоны `.site`. Это нормально в первые часы после покупки: регистратор передаёт домен в реестр, и только после этого записи из панели начинают работать. Если через сутки всё так же — проверь в кабинете Рег.ру, что домен в статусе «Активен» и оплачен.

Проверка через 10–60 минут после делегирования: https://dnschecker.org → `dota2game.site` → должны быть все четыре IP GitHub.

## Шаг 3. Включить GitHub Pages — делаем сейчас

DNS основного домена уже указывает на GitHub, поэтому включаем публикацию.

1. https://github.com/MySoulCry/dota2game → **Settings → Pages**.
2. **Source: Deploy from a branch** → Branch: `main`, folder: `/ (root)` → **Save**.
3. Поле **Custom domain** должно само заполниться `dota2game.site` из файла `CNAME`. Если пусто — впиши вручную и нажми **Save**.
4. Через 1–2 минуты сайт начнёт открываться. Сертификат HTTPS GitHub выпускает сам, обычно за 5–60 минут (иногда до 24 часов).

> Если сразу после включения браузер пишет ошибку сертификата — это нормально: сертификат ещё не выпущен. Подожди и обнови страницу.

### Если сайт всё ещё не открывается

Проверь по порядку:

1. На странице **Settings → Pages** нажата ли кнопка **Save** под блоком «Build and deployment». Без неё ничего не применяется.
2. В **Source** стоит **Deploy from a branch**, а не «GitHub Actions» (workflow мы удалили).
3. Репозиторий **публичный** — на бесплатном аккаунте Pages иначе не работают.
4. Быстрая проверка статуса: открыть в браузере
   `https://api.github.com/repos/MySoulCry/dota2game/pages` —
   если приходит `404 Not Found`, Pages точно не включён.
5. Если всё включено, но сайт отдаёт 404 — подожди пару минут: первая сборка Pages занимает время, статус видно в разделе **Actions** репозитория.

## Шаг 4. HTTPS и проверка

1. Вернись в **Settings → Pages**. Когда GitHub выпустит сертификат (до 24 часов), появится галочка **Enforce HTTPS** — включи её.
2. Проверь по списку:
   - [ ] `https://dota2game.site` открывается без предупреждений браузера;
   - [ ] запускается раунд, матчи подгружаются;
   - [ ] `https://dota2game.site/privacy.html` открывается;
   - [ ] в `privacy.html` вместо «укажи здесь свой e-mail» стоит рабочий адрес;
   - [ ] в онлайне создаётся комната.

⤴ Дальше шаги 5 (Яндекс Реклама) и 6 (донат).

## Шаг 5. Яндекс Реклама (РСЯ)

Код автоматического размещения уже встроен: id площадки **20294363** прописан в `js/config.js`, а скрипты Яндекса подключает `js/monetization.js` (только если реклама включена и не активна версия без рекламы).

Что осталось:

1. **Подтвердить владение сайтом.** В кабинете yandex.ru/ads → «Проверить права на сайт» → способ «Мета-тег». Пришли значение из `content` — вставлю в `index.html` и запушу.
2. **Договор:** самозанятый / ИП / ООО. Без него деньги начисляются, но не выплачиваются.
3. **Модерация площадки:** 1–5 рабочих дней. После неё автоблоки начнут показываться сами.

Если захочется управлять местами вручную: в кабинете можно создать обычные блоки (`R-A-...`), тогда в `js/config.js` очисти `pageId` и впиши их id в `banner` и `gameOver`.

## Шаг 7. Если площадку отклонили

Пришло: «недостаточно реальных посетителей (менее 100 в неделю)» и «не соответствует правилам по иным причинам».

**Первое — это не про код.** РСЯ хочет видеть живой сайт с настоящим трафиком. 100 посетителей в неделю набираются только продвижением, а не правками в файлах.

**Второе обычно означает:** мало контента, нет контактов, сайт выглядит недоделанным. Что уже сделано в проекте:

- страница **«Как играть»** с правилами, режимами, FAQ и описанием проекта;
- **контакты** и e-mail на этой странице;
- **политика конфиденциальности** с разделом про аналитику;
- **sitemap.xml** и **robots.txt** для поисковиков;
- поддержка **Яндекс.Метрики** — её данные РСЯ и смотрит, чтобы засчитать посещаемость.

### Что сделать перед повторной заявкой

1. **Поставить счётчик Метрики.** Открой https://metrika.yandex.ru/add — это сразу форма создания счётчика. Там: имя (например `dota2game`), адрес сайта `https://dota2game.site`, включи «Вебвизор» и «Карту скроллинга», прими условия → «Создать счётчик». Номер счётчика — 8–9 цифр, он показывается в списке и в коде (`ym(12345678, 'init'`).
   Если прямой ссылки нет — открой https://metrika.yandex.ru/list (список счётчиков) и нажми «+ Добавить счётчик» / «Создать счётчик» справа сверху. Если и списка нет — скорее всего ты внутри уже открытого счётчика: вернись к списку через меню слева.
   Пришли мне номер — впишу в `js/config.js` (поле `analytics.yandexMetrika`) и запушу. Без счётчика посещаемость не подтвердить.
2. Добавить сайт в **Яндекс Вебмастер** и подтвердить его тем же способом.
3. **Загнать первых посетителей.** Работающие каналы для Dota 2:
   - посты и комментарии в VK-сообществах по Dota 2, Telegram-чатах и каналах (без спама — с ссылкой на конкретный режим);
   - DTF, Pikabu, Reddit r/DotA2 (для англоязычной аудитории);
   - друзья и пати: комнаты рассчитаны именно на игру компанией, ссылка-приглашение уже работает;
   - короткие видео «угадай героя по сборке» с ссылкой в описании.
4. ⚠️ Не накручивай трафик: РСЯ и Метрика это видят, будет повторный отказ.

### Что делать, пока трафика мало

- **Донат** — Boosty или DonationAlerts, ссылка в `brand.donateUrl`; кнопка «Поддержать» уже на сайте.
- **Партнёрские сети для малых сайтов** (Adsterra, Gnezdo и подобные) — берут почти всех, но доход мизерный и реклама навязчивая.
- **Прямой баннер** у знакомого магазина/сообщества: на малом трафике часто выгоднее сетей.
- Ничего не мешает **повторно отправить заявку в РСЯ** через 2–4 недели, когда посещаемость подрастёт.
