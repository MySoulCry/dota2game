# Угадай героя — Dota 2 по сборкам

Сайт: **https://dota2game.site**

Браузерная викторина без сборки: один `index.html` + CSS + JS. Играется в любом браузере, работает на телефоне.

Показываем сборку предметов из **реального завершённого матча Dota 2**, ранг и примерный MMR, время и режим матча — нужно угадать героя. После ответа открываются ссылки на матч (OpenDota и Dotabuff).

## Что внутри

- `index.html` — все экраны: главная, онлайн, лобби комнаты, викторина, итоги, рейтинги.
- `how-to-play.html` — правила, режимы, FAQ и описание проекта (полезно для модерации рекламы и поисковиков).
- `styles.css` — оформление и адаптив.
- `js/config.js` — **единственный файл для настройки**: данные, комнаты, реклама, донат.
- `js/data.js` — загрузка каталогов героев и предметов и сборка вопросов из реальных матчей через OpenDota.
- `js/rooms.js` — онлайн-комнаты: создание, вход по коду, быстрый подбор, обмен сообщениями.
- `js/leaderboard.js` — общий рейтинг: каждый браузер публикует свой лучший результат в общий канал.
- `js/app.js` — экраны, одиночная игра, таблица рейтингов, связка с комнатами.
- `js/monetization.js` — реклама, донат, платная версия без рекламы, награда за просмотр.
- `js/metrics.js` — счётчик Яндекс.Метрики (номер задаётся в настройках).
- `robots.txt`, `sitemap.xml` — для поисковых систем.
- `privacy.html` — политика конфиденциальности (её обычно требует AdSense).
- `manifest.webmanifest`, `icons/`, `sw.js` — установка сайта как приложения (PWA).
- `PLAY.md` — как выложить в RuStore или Google Play.
- `marketing/shots.html` — готовые кадры 9:16 для соцсетей: листаешь на телефоне и снимаешь скриншоты.
- `.nojekyll` — чтобы GitHub Pages не пропускал файлы через Jekyll.

## Откуда данные

Вопросы собираются **на живом API** [OpenDota](https://docs.opendota.com/), без ключа:

1. Берём свежие публичные матчи (`/api/publicMatches`) и достаём из них игроков.
2. Смотрим историю этих игроков (`/api/players/{id}/matches`) и оставляем **только рейтинговые** матчи (`lobby_type = 7`); Turbo (`game_mode = 23`) и обычные пабы отбрасываются.
3. Подгружаем детали выбранных матчей (`/api/matches/{id}`).
4. Выбираем игрока с полной сборкой и известным рангом, показываем его 6 предметов.

Ранг — это медаль игрока (`rank_tier` из матча). **MMR в API не отдаётся**, поэтому показывается оценка по медали (Herald ≈ 0–770, Immortal ≈ 5420+). Это подписано в интерфейсе как «≈».

Собранная пачка вопросов кэшируется в браузере (`api.cacheMinutes`), поэтому вторая игра стартует мгновенно. Если OpenDota недоступен — игра честно скажет об ошибке, а не покажет выдуманные матчи.

Изображения героев и предметов берутся с CDN Valve (`cdn.cloudflare.steamstatic.com`).

## Одиночная игра

- 10 раундов, 20 секунд на вопрос.
- Очки: 50 за верный ответ + до 50 за скорость + бонус за серию (до 40).
- Подсказка 50/50: бесплатно, а если включена реклама — за просмотр ролика.
- Таблица рейтингов хранится в браузере (`localStorage`).

## Онлайн-комнаты

- До **5 игроков**, играть можно **от 2**.
- Создать комнату **по коду** (для друга) или **открытую** — её видно в списке и её находит «быстрый подбор».
- Ссылка-приглашение вида `сайт/?room=ABC12` подставляет код автоматически.
- Настройки комнаты: число раундов и время на вопрос.
- Хост авторитетен: он готовит вопросы, принимает ответы и считает очки; у остальных ничего не считается на клиенте.

**Как это работает без своего сервера.** Обмен сообщениями идёт через открытый MQTT-брокер (`wss://broker.emqx.io:8084/mqtt`) — бесплатно и без регистрации. Топики:

- `dotaguess/v1/lobby/{код}` — открытые комнаты для списка и подбора;
- `dotaguess/v1/room/{код}` — состояние комнаты (список игроков, настройки;
- `dotaguess/v1/room/{код}/in` — сообщения игроков хосту;
- `dotaguess/v1/room/{код}/out` — вопросы, результаты и итоги от хоста.

Брокер меняется в `js/config.js` (`rooms.brokerUrl`). Если он недоступен (например, сеть блокирует WebSocket), игра сама переключится на локальный режим через `BroadcastChannel` — тогда комнату видно только во вкладках этого браузера, и интерфейс об этом честно предупредит.

Публичный брокер — это общий канал: не отправляй туда ничего личного, а ники и очки видны участникам комнаты. Для серьёзного продакшена стоит поднять свой брокер/сервер и добавить авторизацию.

## Общий рейтинг

Таблица на экране «Рейтинги» — общая для всех посетителей: браузер публикует лучший результат в retained-топик `dotaguess/v1/scores/{playerId}`, а у каждого клиента таблица собирается из всех таких записей и обновляется в реальном времени. Сервера и аккаунтов не нужно — используется тот же брокер, что и для комнат.

Ограничение честное: результат нельзя защитить от подмены, потому что проверка идёт на стороне клиента. Для дружеского рейтинга этого достаточно; для соревновательного нужен сервер.

## Куда выложить сайт бесплатно

Подробный чек-лист по домену, DNS и рекламе — в [`DEPLOY.md`](DEPLOY.md).

Сайт — это просто папка с файлами (`index.html`, `styles.css`, `js/`, `privacy.html`, `ads.txt`). Сборки нет, поэтому подойдёт любой статический хостинг.

| Вариант | Цена | Что получаешь |
| --- | --- | --- |
| **GitHub Pages** | бесплатно | адрес `https://<ник>.github.io/<репозиторий>/`, HTTPS, деплой из git |
| **Netlify Drop** | бесплатно | перетащил папку — получил адрес `https://<имя>.netlify.app` |
| **Cloudflare Pages / Vercel** | бесплатно | то же самое, деплой из git |

Платить обычно приходится только за **свой домен** (`ugaday-geroya.ru` и т.п.) — 300–1500 ₽ в год у регистратора. Он не обязателен, но с доменом проще пройти модерацию рекламы и выглядит солиднее.

### Вариант 1: GitHub Pages (по шагам)

1. Зарегистрируйся на github.com.
2. **New repository** → имя, например `dotaguess` → **Public** (на бесплатном аккаунте Pages работают только в публичных репозиториях) → Create.
3. Залей файлы:
   - проще всего через сайт: **Add file → Upload files** и перетащить `index.html`, `styles.css`, `privacy.html`, `ads.txt`, папку `js` и файл `.nojekyll` (без него GitHub может прогнать файлы через Jekyll и что-то потерять);
   - либо из терминала: `git remote add origin https://github.com/<ник>/dotaguess.git` и `git push -u origin main`.
4. **Settings → Pages → Source: Deploy from a branch**, Branch: `main`, folder: `/ (root)` → **Save**.
5. Через 1–2 минуты сайт откроется: `https://<ник>.github.io/dotaguess/`.

Дальше — привязать домен и включить HTTPS: см. [`DEPLOY.md`](DEPLOY.md).

### Вариант 2: Netlify без git

1. Открой app.netlify.com/drop.
2. Перетащи папку с сайтом.
3. Получи ссылку вида `https://random-name.netlify.app` — имя меняется в настройках.

### Проверка после публикации

- открывается главная и запускается раунд;
- открывается `https://твой-адрес/privacy.html`;
- в онлайне создаётся комната (если открытый брокер доступен; иначе игра честно предупредит про локальный режим).

## Как подключить рекламу

Все настройки — в `js/config.js`, в блоке `ads`. Провайдер выбирается полем `provider`: `yandex` (РСЯ) или `adsense`.

### Яндекс Реклама (РСЯ) — основной вариант для РФ

Google AdSense с 2022 года не платит издателям из РФ, поэтому для русской аудитории работает Яндекс.

1. **Кабинет.** yandex.ru/ads → зарегистрироваться как площадка (сайт) → заключить договор (самозанятый, ИП или ООО — без него выплат не будет).
2. **Добавить площадку** — домен `dota2game.site`, подтвердить владение мета-тегом (место в `index.html` подготовлено) или файлом.
3. **Дождаться модерации** — обычно 1–5 рабочих дней.
4. **Включить рекламу** — в `js/config.js` уже стоит провайдер, флаг и id площадки:

```js
ads: {
  enabled: true,
  provider: 'yandex',
  yandex: {
    pageId: '20294363', // id площадки → автоматическое размещение
    banner: '',
    gameOver: ''
  }
}
```

В режиме автоматического размещения Яндекс сам вставляет рекламные блоки на страницу, и пустые рамки слотов в игре скрываются. Отдельные блоки (`R-A-...`) нужны только если хочется управлять местами вручную — тогда `pageId` оставь пустым, а id блоков впиши в `banner` / `gameOver`.

### Google AdSense (если аудитория не только из РФ)

1. **Аккаунт.** adsense.google.com → зарегистрироваться, указать страну, адрес, данные.
2. **Добавить сайт.** AdSense → Sites → Add site → адрес сайта. Google выдаст Publisher ID вида `ca-pub-1234567890123456`.
3. **Подтвердить владение.** Google предложит мета-тег или файл. Для GitHub Pages проще всего вписать свой `pub-...` в `ads.txt` в корне сайта (файл уже есть) и/или добавить `<meta name="google-site-verification" content="...">` в `<head>` в `index.html`.
4. **Дождаться проверки.** Обычно от нескольких часов до 2 недель. Нужны рабочий сайт, политика конфиденциальности (она есть) и понятный контент.
5. **Создать блоки.** AdSense → Ads → By ad unit → Display ads. Получишь `data-ad-slot` — число (например `1234567890`), отдельное для каждого блока.
6. **Вписать в `js/config.js`:**

```js
ads: {
  enabled: true,
  provider: 'adsense',
  client: 'ca-pub-1234567890123456', // Publisher ID
  slots: {
    banner: '1234567890',   // баннер под контентом
    gameOver: '0987654321'  // блок на экране итогов
  },
  rewardedUrl: '',
  rewardedSeconds: 5
}
```

7. Обновить страницу. Пока аккаунт не одобрен или поля пустые — на месте блоков показывается заглушка «Рекламный блок…», это нормально.

### Правила AdSense, которые легко нарушить

- Нельзя кликать по своей рекламе и просить об этом других — за это блокируют аккаунт.
- Для посетителей из ЕС нужен баннер согласия на cookie. Проще всего включить готовое сообщение Google: AdSense → Privacy & messaging → GDPR message → создать и опубликовать (код подключать не нужно, Google отдаст его сам).
- `ads.txt` в корне подтверждает, кто имеет право продавать рекламу на сайте: впиши туда свой `pub-...`.
- Нельзя ставить рекламу в попапы поверх контента и на страницы без содержания.

### Донат и партнёрки

- **донат** — быстрее всего даёт первые деньги: Boosty, DonationAlerts, Buy Me a Coffee (кнопки уже есть, впиши ссылку в `brand.donateUrl`);
- **партнёрские сети, VK, Telegram-канал** рядом с игрой;
- прямой баннер у знакомого магазина или сообщества — на малом трафике иногда выгоднее РСЯ.

Другой провайдер подключается в одном месте — функция `renderSlot()` в `js/monetization.js`: она получает контейнер и рисует в нём блок. Остальной код (слоты на странице, отключение для «версии без рекламы») менять не нужно.

### Остальные кнопки

- **Донат:** `brand.donateUrl` — ссылка на Boosty / DonationAlerts / Buy Me a Coffee.
- **Версия без рекламы:** `brand.proUrl` — ссылка на оплату; после оплаты человек открывает сайт с `?pro=1`, реклама отключается (флаг хранится в браузере). Автоматическая выдача доступа — только со своим сервером.
- **Подсказка за рекламу:** работает через `Monetize.showRewarded`; для настоящего провайдера впиши `ads.rewardedUrl` или замени функцию.

### Чек-лист перед публикацией

- [ ] в `js/config.js` заполнены `brand.donateUrl` и `brand.proUrl` (или осознанно оставлены пустыми — кнопки покажут подсказку);
- [ ] в `js/config.js` в `ads.yandex` стоят id блоков РСЯ (или `ads.enabled: false`);
- [ ] в `privacy.html` указан рабочий e-mail;
- [ ] если используешь AdSense — в `ads.txt` стоит свой publisher ID;
- [ ] после публикации проверены ссылка на матч в раунде и создание комнаты.

## Настройки

```
api: { poolSize: 12, cacheMinutes: 20, minRankTier: 40 }
rooms: { maxPlayers: 5, minPlayers: 2, brokerUrl: '...' }
analytics: { yandexMetrika: '' }   // номер счётчика Метрики
```

`minRankTier`: 11–15 Herald, 21–25 Guardian, 31–35 Crusader, 41–45 Archon, 51–55 Legend, 61–65 Ancient, 71–75 Divine, 80 Immortal. Это только приоритет: матчи ниже порога тоже попадают в игру, если рейтинговых не хватает.

Вопросы собираются **только из рейтинговых матчей** (`lobby_type = 7`), Turbo и обычные пабы не используются.

## Ограничения, о которых стоит знать

- Верный ответ в комнате приходит от хоста, поэтому теоретически его можно подсмотреть в трафике. Для дружеской викторины это нормально; для соревновательной нужен сервер с проверкой на своей стороне.
- Таблица рейтингов локальная (на устройстве). Общая — только со своим сервером.
- OpenDota — бесплатный API с лимитами; при активной игре пачка вопросов кэшируется, но при массовом наплыве игроков лучше получить свой ключ/прокси.
