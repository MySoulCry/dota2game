# Выложить игру в магазин

Короткая правда: «бесплатно и в Google Play» одновременно не получится. Платно не приложение, а аккаунт разработчика. Ниже — что можно бесплатно и что нужно для Play.

## 1. Бесплатно и прямо сейчас: установка как приложение (PWA)

Сайт уже готов к установке — это работает без магазинов:

- **Android / Chrome:** открыть `https://dota2game.site` → меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).
- **iPhone / Safari:** открыть сайт → «Поделиться» → **На экран «Домой»**.

Появится иконка, приложение открывается без адресной строки, а service worker держит базовый кэш для офлайна. В проекте для этого уже есть:

- `manifest.webmanifest` — имя, иконки, цвета, полноэкранный режим;
- `icons/icon.svg`, `icons/icon-maskable.svg`;
- `sw.js` — сеть первым, кэш только как запасной вариант (новая версия сайта не залипает);
- мета-теги для iOS и Android в `index.html`;
- HTTPS на домене — обязательное условие, он уже настроен.

Иконки в PNG (их просят магазины) делаются одной кнопкой: открой `https://dota2game.site/icons/make-png.html` и скачай 512×512 и 192×192.

## 2. RuStore — бесплатно

Российский магазин, регистрация разработчика бесплатная, физлицу достаточно паспорта и ИНН/самозанятости.

1. rustore.ru → «Стать разработчиком».
2. Заполнить карточку приложения: название, описание, категория «Игры», иконка 512×512, 3–5 скриншотов.
3. Загрузить **APK** (как его собрать — ниже).
4. Пройти модерацию (обычно 1–3 дня).

## 3. Google Play — платно и с условиями

- **Аккаунт разработчика — 25 $ один раз**, нужна карта, которая проходит за рубежом.
- Верификация личности (паспорт).
- Для **новых личных аккаунтов** обязателен закрытый тест: **не меньше 12 тестеров в течение 14 дней**, потом можно просить доступ к публикации.
- Нужны: политика конфиденциальности (есть — `https://dota2game.site/privacy.html`), Data safety, рейтинг содержания, скриншоты, feature graphic 1024×500, иконка 512×512, target SDK не ниже требуемого Google.

## 4. Как собрать APK из сайта (TWA)

Сайт превращается в Trusted Web Activity — приложение открывает ваш же сайт, без браузерной строки.

Нужен **компьютер** (Windows/macOS/Linux) с Node.js и Java:

```
npx @bubblewrap/cli init --manifest https://dota2game.site/manifest.webmanifest
npx @bubblewrap/cli build
```

Bubblewrap спросит иконку (PNG 512×512), имя пакета (например `site.dota2game.quiz`) и создаст подписанный APK/AAB. Дальше файл загружается в RuStore или Play.

Альтернатива без командной строки — **Android Studio**: новый проект, WebView-активность с загрузкой `https://dota2game.site`, иконка, подпись, сборка.

Важно: TWA открывает живой сайт, поэтому обновления игры выкатываются сразу, без пересборки приложения. Но и требования Play (политика, Data safety) всё равно нужно заполнить.

## 5. Про рекламу в приложении

Даже если приложение выйдет в Play, **AdMob, как и AdSense, не платит издателям из РФ**, поэтому доход даст не реклама в приложении, а:

- донат (Boosty / DonationAlerts) — ссылка в настройках сайта;
- РСЯ на сайте, когда площадку одобрят;
- прямые договорённости.
