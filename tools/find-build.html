Найти матч по сборке

Инструмент ищет реальные завершённые матчи, где у героя в конце игры были все выбранные предметы. По умолчанию подставлен набор из рекламного макета: Anti-Mage, Blink, Battle Fury, Manta, Butterfly, Abyssal Blade, Power Treads.

Ищем через SQL-выборку OpenDota по инвентарю на конец матча. Если сервис отвечает ошибкой доступа к explorer — значит, SQL-запросы для бесплатного тарифа закрыты, тогда скажи: сделаю поиск через историю игроков.
